为「一边干活一边问 AI」设计

不打断你正在看的页面，AI 常驻右侧，随叫随到。

🧲

AI 一下

在任意网页选中文字 → 右键 →「AI 一下」，侧边栏自动打开并把内容连同页面标题一起填进输入框，接着问就行。

⇄

多 AI 并排对比

按住 Ctrl 点 2~4 个图标，分栏并排展示、一问多答。拖动分隔条自由调宽度，布局会记住。

🔄

会话各自保留

图标栏点谁用谁，各站点会话独立保存——切走再切回来，上下文原样还在。

🪟

独立小窗兜底

站点拒绝内嵌（如 ChatGPT）？一键弹出 430px 贴边小窗继续用，登录态照样共享。

🧩

任意站点自定义

顶栏 ＋ 添加任何 AI 网页版，favicon 自动抓取；顶栏图标支持拖拽排序。

⌨️

键盘顺手

Ctrl+1~4 快速多选、Esc 退出对比、双击分隔条复位均分，全程手不离键盘。

三步装好

需要 Chrome / Edge 114 及以上版本

克隆仓库

把扩展源码拉到本地任意目录。

git clone https://github.com/1parado/deepseek-sider.git

加载扩展

打开 chrome://extensions/，开启右上角「开发者模式」，点「加载已解压的扩展程序」，选择克隆出的文件夹。

登录一次即可

点工具栏图标打开侧边栏，选一个 AI 登录——共用浏览器 cookie，真实标签页和侧边栏共享登录态。
